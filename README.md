# 相撲クラブ

川や海でカニをつかまえて水槽で育て、近所の子どもたちと「カニ相撲」で勝負する、夏休みのブラウザゲームです。
three.js で描画しています。テクスチャ・カニのモデル・効果音はすべてプログラムで生成しています。BGM も下記のとおりプログラムで作曲しています。

## 遊び方

- **川へ行く／海へ行く**：石をタップしてひっくり返し、出てきたカニが逃げている間にタップしてつかまえます。ハサミを振り上げて威嚇しているときに手を出すと、はさまれて逃げられます。
- **カゴ罠**：白い輪の場所にエサ（煮干し／スルメ）を入れたカゴを沈め、時間をおいてから引き上げます。夜をまたぐと大物が入りやすくなります。
- **水槽**：はじめは5匹まで飼えます。相撲で勝ち進むと水槽が広くなり、カゴも増えます。エサは1日1回。
- **カニ相撲**：水槽から1匹選んで土俵（切り株）に上げます。
  1. **仕切り**：指でカニの背中を押して気合を入れます（最大3回）。ゲージの緑〜黄色で押すと気合が上がり、赤（押しすぎ）だと怒ってはさまれます。
  2. **はっけよい**：取組はカニ同士が自分で戦います。押し合い・ハサミ攻撃・いなし・ひっくり返しなどがあり、押し出すか、ひっくり返すか、相手が逃げ出せば勝ちです。
  3. 取組中も3回まで「つつく」ことができ、ひるんだカニを立ち直らせたり、気合を入れ直したりできます。

## 登場するカニ（14種）

サワガニ（赤・青・白・茶の色違い）、アカテガニ、ベンケイガニ、クロベンケイガニ、モクズガニ、シオマネキ、ノコギリガザミ、イソガニ、ヒライソガニ、ショウジンガニ、イシガニ、ガザミ、タイワンガザミ、スベスベマンジュウガニ。
同じ種でも、大きさ・性別・性格・力／踏ん張り／根性／素早さ／気性、色合いが1匹ずつ違います。

## BGM

BGM とジングルは、作曲アプリ「かなでる」（[cadmium2525/mp4mp3](https://github.com/cadmium2525/mp4mp3) の `daw/`）のエンジンで作っています。

| ファイル | 場面 | 内容 |
| --- | --- | --- |
| `audio/home.mp3` | 水槽（昼） | 縁側の午後。F メジャー 84BPM、ナイロンギター・ビブラフォン・フルート・風鈴 |
| `audio/field.mp3` | 川・海（昼） | 川あそび。D メジャー 108BPM、マリンバ・ピチカート・カリンバ |
| `audio/night.mp3` | 夜 | 夜の水辺。A マイナー 70BPM、パッド・オルゴール・ピアノ |
| `audio/sumo.mp3` | 相撲 | 土俵の熱戦。D マイナー 128BPM、太鼓・鉦・琴・笛 |
| `audio/win.mp3` `lose.mp3` `catch.mp3` | ジングル | 勝ち・負け・捕獲 |

曲は `tools/music/gen.mjs` が曲 JSON（`tools/music/songs/`）を作り、`tools/music/build.sh` で音にします。

```sh
git clone https://github.com/cadmium2525/mp4mp3 ../mp4mp3
KANADERU=../mp4mp3/daw sh tools/music/build.sh          # 全曲
KANADERU=../mp4mp3/daw sh tools/music/build.sh sumo     # 1曲だけ
```

`tools/music/sheets/*.txt` に、ラウドネス・和音の検出結果・スマホのスピーカーでの聞こえ方などの解析結果が出ます（`--sheet` の画像はリポジトリには入れていません）。
ループ曲は、ファイルの末尾の余韻に次のループを重ねて再生するので、つなぎ目なく続きます（`js/audio.js` の `TRACKS` に小節数とテンポを書いています）。

## 公開（GitHub Pages）

ビルド不要の静的サイトです。リポジトリの **Settings → Pages** で、Source を「Deploy from a branch」、ブランチを公開したいブランチの `/ (root)` にすると公開されます。

### PWA（ホーム画面に追加）

`manifest.webmanifest` と `sw.js` により、スマホのホーム画面に追加してアプリのように全画面で遊べます。一度開けばオフラインでも動きます。
ゲームのファイルを更新したときは、`sw.js` の `VERSION` を上げてください（古いキャッシュが入れ替わります）。新しいファイルを追加した場合は `ASSETS` にも追記します。

ローカルで動かす場合は、リポジトリのフォルダで簡易サーバーを立ててください（ES Modules を使うため `file://` では動きません）。

```sh
python3 -m http.server 8000
# http://localhost:8000/ を開く
```

## 構成

- `index.html` / `css/style.css` … 画面とUI
- `js/main.js` … 画面遷移・ループ
- `js/scenes/tank.js` … 縁側の水槽（ホーム）
- `js/scenes/field.js` … 川・海でのカニとり
- `js/scenes/sumo.js` … カニ相撲
- `js/crab.js` … カニの3Dモデル（手続き生成）
- `js/textures.js` … 手続き的テクスチャ
- `js/data.js` … 種・個体差・対戦相手
- `vendor/three/` … three.js r170（MIT License）
